# Security & Responsible AI Policy

## Responsible Voice Cloning Guidelines

VoxPoly Studio is built for legitimate multilingual content creation, accessibility, education, podcasting, and localization. By using this software, you agree to:

1. **Consent First**: Only clone your own voice or voices for which you have obtained explicit, informed consent from the speaker.
2. **No Impersonation or Fraud**: Never use generated audio or dubbed videos for impersonation, social engineering, defamation, political disinformation, or bypassing voice biometrics.
3. **Transparency & Watermarking**: Keep the built-in imperceptible acoustic watermark enabled (`enable_watermark: true`) whenever publishing or sharing generated media, and disclose synthetic audio where required by applicable laws.

## Deployment Security (v3.0.1 Hardened)

- **Local Loopback by Default**: Both local launch scripts and `docker-compose.yml` (`127.0.0.1:8765:8765`) bind strictly to host loopback by default. Never expose port `8765` to a LAN or public internet without setting a strong `VOXPOLY_ACCESS_TOKEN` (>= 12 characters).
- **Colab Private by Default & Tunnel Lifecycle**: In `colab/VoxPoly_Colab.ipynb`, `ENABLE_PUBLIC_CLOUDFLARE_URL` defaults to `False`. Both Step 3 and Step 4 run `stop_cloudflared()` (verifying `pgrep` exit status `1`, escalating to `SIGKILL`, and cleaning up even on `KeyboardInterrupt`) before restarting or disabling public exposure, and Step 4 refuses to start a public Cloudflare tunnel unless `/api/health` confirms `v3.0.1+` media protection and a >= 12-character `ACCESS_TOKEN`. Never commit or share a notebook with a real passcode filled into Step 3.
- **Full-Site Default-Deny Authentication (Router-Matched ASGI Path)**: When `VOXPOLY_ACCESS_TOKEN` is set, the auth middleware evaluates the exact ASGI route path (`starlette._utils.get_route_path`, immune to `Host`-header URL mismatch and reverse-proxy `root_path` divergence; `starlette>=1.0.1` pinned). Every non-public route — including `/api/*`, `/v1/*`, `/media/*`, `/docs`, `/redoc`, and `/openapi.json` — requires either a header token (`X-Access-Token` or `Authorization: Bearer`) or a revocable random ASCII `HttpOnly; SameSite=Lax` session cookie issued by `POST /api/auth/session` (constant-time `hmac.compare_digest` check, bounded per-IP failed-auth rate limit — intentionally throttling further raw-token guesses from the offending IP for 60s to prevent brute-force oracles while keeping already-authenticated session cookies active and supporting `VOXPOLY_TRUST_CF_IP=1` behind local Cloudflare Tunnel — same-origin + custom-header CSRF protection on cookie-authenticated mutations, `DELETE /api/auth/session` server-side revocation, and `Cache-Control: private, no-store` on protected & session responses). URL query-string tokens are never accepted.
- **Canonical Allowlist Media Serving**: `/media/{bucket}/{file_path}` resolves canonical filesystem paths inside the target bucket and serves only strictly allowlisted audio, video, and subtitle extensions (`.wav`, `.mp3`, `.mp4`, `.mov`, `.mkv`, `.webm`, `.m4a`, `.ogg`, `.flac`, `.aac`, `.opus`, `.srt`, `.ass`), preventing exposure of `index.json`, `.tmp` files, dotfiles, or Windows filename aliases (`index.json.`, trailing spaces, 8.3 short names).
- **Outbound URL & SSRF Boundaries**:
  - **Web Article Importer (`/api/documents/import-url`)**: Uses a fresh per-hop connection-pinned HTTP client (`backend/net_safety.py`, blocking loopback, private LAN, link-local/cloud metadata, CGNAT, and IPv6 `fec0::/10` / mapped / 6to4 / Teredo private addresses), disables environment proxies (`trust_env=False`), enforces `Accept-Encoding: identity`, and bounds DNS/per-read timeouts and cumulative wall-clock deadline (20s) plus raw payload size (5 MiB).
  - **Video URL Ingestion (`/api/videos/import-url`)**: Runs `yt-dlp` inside an isolated subprocess (`backend/safe_ytdlp.py`) that strips proxy env vars, wraps `socket.getaddrinfo` to reject non-public IP resolutions, disables yt-dlp's external network downloaders (`ExternalFD` / network `FFmpegFD`) and blocks network URLs in child `subprocess.Popen` calls, disables the `-generic` HTML scraper extractor by default, enforces a cumulative multi-track byte cap across video+audio streams (`MAX_VIDEO_MB`), and restricts local FFmpeg/FFprobe calls to `-protocol_whitelist file,pipe`. For untrusted multi-tenant deployments, additionally enforce OS/container-level egress firewalling.
  - **Custom LLM Settings (`/api/settings` & `_call_llm_json`)**: Changing `llm_api_base` without supplying a new `llm_api_key` automatically clears the previously stored key; in token-protected deployments, private/loopback `llm_api_base` URLs are blocked at both save time AND connection time (via connection-pinned `post_public_json` with redirects disabled) unless the operator explicitly sets `VOXPOLY_ALLOW_LOCAL_LLM=1`.
- **Secrets**: Never commit `data/settings.local.json` or `.env` files containing third-party LLM API keys. They are ignored by `.gitignore`.

## Reporting Vulnerabilities

If you discover a security issue in VoxPoly Studio, please open a private security advisory on GitHub instead of posting exploit details publicly.
